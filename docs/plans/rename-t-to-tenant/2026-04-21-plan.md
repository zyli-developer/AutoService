# Rename `/t/` → `/tenant/` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the tenant URL prefix from `/t/<tenant_id>/...` to `/tenant/<tenant_id>/...` across backend middleware, URL builders, frontend router configs, all tests, and user-facing hints — atomically, with no dual-route support.

**Architecture:** The `/t/` prefix is a plain-string constant used in 4 places at the backend (middleware `path.startswith(...)`, admin redirect builder, onboarding URL builder, docstrings) and in 11 places at the frontend (React Router `<Route path>`, basename computation, iframe `src`, shell nav links, one i18n hint string). No runtime state or DB data depends on the literal string, so a string-level rename covers everything. One PR, one commit per task (code + tests together), merged atomically after M3 gate lands.

**Tech Stack:** FastAPI (backend routing + Starlette middleware) · React Router v6 (frontend) · pytest + vitest (tests) · no build-step code generation uses `/t/`.

Replace lines 289-322 in [autoservice/web_gateway.py:289-322](../../../autoservice/web_gateway.py#L289-L322) — every `/t/` literal becomes `/tenant/`. The final block should read:

```python
    # T7B.1 — TenantContext middleware (spec §3.2).
    #
    # Populates request.state.deployment_mode + request.state.tenant_id and
    # — in tenant mode — rewrites /tenant/<self>/* to /* (URL-flat fork
    # routing) while refusing cross-tenant paths /tenant/<other>/* with 403.
    #
    # Placement: registered AFTER the CORSMiddleware add_middleware call so
    # Starlette wraps it INSIDE CORS (Starlette chains in reverse registration
    # order). That is the desired order — CORS headers attach to our 403
    # responses, and CORS-only preflight OPTIONS requests still reach us
    # unchanged.
    @app.middleware("http")
    async def tenant_context_middleware(request: Request, call_next):
        from autoservice import bootstrap

        try:
            mode = bootstrap.get_deployment_mode()
        except (FileNotFoundError, ImportError):
            mode = "master"

        request.state.deployment_mode = mode
        request.state.tenant_id = (
            bootstrap.get_tenant_id() if mode == "tenant" else None
        )

        if mode == "tenant":
            self_tid = request.state.tenant_id
            path = request.url.path
            if self_tid and path.startswith(f"/tenant/{self_tid}/"):
                # Strip the /tenant/<self> prefix so the fork's URL-flat
                # routes receive the request (spec §3.2 "fork 模式 URL-flat").
                request.scope["path"] = path[len(f"/tenant/{self_tid}"):] or "/"
            elif self_tid and path == f"/tenant/{self_tid}":
                request.scope["path"] = "/"
            elif path.startswith("/tenant/"):
                # Cross-tenant attempt in single-tenant fork → refuse.
                return JSONResponse(
                    status_code=403,
                    content={
                        "error": (
                            "cross-tenant access denied "
                            "(tenant-mode single-tenant fork)"
                        ),
                    },
                )

        return await call_next(request)
```
