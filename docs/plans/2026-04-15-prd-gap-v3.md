## 〇、v3 相对 v2 的结构性变化

| 维度 | v2（飞书主） | v3（Web 首发 + zchat） |
|---|---|---|
| 首发渠道 | 飞书 IM | 独立 Web 页 |
| 对话引擎 | AutoService 自建 conversation.py | zchat channel-server（不在本仓库） |
| Mode/Gate/Timer/Event | AutoService 实现 | zchat 协议级提供 |
| 飞书卡片/PATCH/建群/审批 | AutoService 亲自调 API | zchat feishu_bridge 承接（后续） |
| 客服工作区 | 飞书分队群 thread | **客服 Web 工作台**（本期）|
| 管理群 | 飞书群 | **admin-portal 通知中心**（本期）|
| AutoService 代码估算 | ~15000 行（含飞书） | **~13000 行**（剥离 ~1845 + 新增 ~1100）|
| 工作流 | γ 商务 + α 引擎 + β 交互 | **α App 业务层 + β Web 前端**（γ 商务由 zchat 承担）|

**本 v3 的角色**：重新定义 AutoService 在 v1.1 边界下的"真实缺口"——排除所有已下沉到 zchat 的任务，只列 AutoService App 层 + Web 前端 + 契约层任务。
