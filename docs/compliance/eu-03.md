# eu-03: 数据处理同意机制 (Consent mechanism for data processing)

> 法规: GDPR Art.6(1)(a) | 等级: critical | 地区: EU

## 违规说明

未在处理个人数据前获得用户明确同意。GDPR 要求数据处理必须有合法基础，用户同意是最常用的基础之一。

## 补救步骤

1. 启用同意机制：将 `tenant.consent_mechanism_enabled` 设为 `true`
2. 在客户聊天界面首次交互前展示同意弹窗或声明
3. 记录用户同意时间戳，确保可审计

## 配置示例

```yaml
tenant:
  consent_mechanism_enabled: true
```

## 参考资料

- GDPR Art.6(1)(a) — Lawfulness of processing: consent
- GDPR Art.7 — Conditions for consent（同意必须自由、具体、知情、明确）
