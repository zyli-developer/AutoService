# eu-02: 隐私政策链接 (Privacy policy link)

> 法规: GDPR Art.13 | 等级: critical | 地区: EU

## 违规说明

未向用户提供可访问的隐私政策链接。GDPR 要求在收集个人数据之前，数据控制者必须向数据主体提供关于数据处理的信息。

## 补救步骤

1. 准备隐私政策页面并发布到可公开访问的 URL
2. 在租户配置中填写隐私政策链接：设置 `tenant.privacy_policy_url`
3. 确认客户聊天界面中隐私政策链接可见且可点击

## 配置示例

```yaml
tenant:
  privacy_policy_url: "https://example.com/privacy-policy"
```

## 参考资料

- GDPR Art.13 — Information to be provided where personal data are collected from the data subject
- 链接必须指向当前有效的隐私政策文档
