# eu-05: 用户删除权 (Right to erasure)

> 法规: GDPR Art.17 | 等级: high | 地区: EU

## 违规说明

未提供用户数据删除功能。GDPR 赋予数据主体"被遗忘权"，即在特定条件下请求删除其个人数据的权利。

## 补救步骤

1. 启用删除权功能：将 `tenant.right_to_erasure_enabled` 设为 `true`
2. 确保系统支持按用户请求删除对话记录和个人数据
3. 在隐私政策或客户界面中说明如何行使删除权

## 配置示例

```yaml
tenant:
  right_to_erasure_enabled: true
```

## 参考资料

- GDPR Art.17 — Right to erasure ('right to be forgotten')
- 删除请求应在 30 天内响应
