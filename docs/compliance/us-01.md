# us-01: 数据收集披露 (Data collection disclosure)

> 法规: CCPA §1798.100(b) | 等级: critical | 地区: US

## 违规说明

未向消费者披露所收集的个人信息类别。CCPA 要求企业在收集个人信息时或之前，告知消费者将收集的信息类别及用途。

## 补救步骤

1. 启用数据收集披露：将 `tenant.data_collection_disclosure` 设为 `true`
2. 在客户界面首次交互前展示数据收集说明
3. 确保披露内容包含收集的数据类别和使用目的

## 配置示例

```yaml
tenant:
  data_collection_disclosure: true
```

## 参考资料

- CCPA §1798.100(b) — Right to know what personal information is being collected
- 披露须在收集行为发生前完成
