# cn-03: 个人信息跨境限制 (Cross-border data transfer restriction)

> 法规: PIPL §38-39 | 等级: critical | 地区: CN

## 违规说明

未经合规授权将个人数据传输至境外。PIPL 要求向境外提供个人信息须满足特定条件（安全评估、标准合同、认证等）。

## 补救步骤

1. 确认数据不跨境传输：将 `tenant.data_cross_border_enabled` 设为 `false`
2. 如确需跨境传输，须完成以下之一：
   - 通过国家网信部门安全评估
   - 经专业机构认证
   - 签订标准合同并报备
3. 确保 AI 模型调用和数据存储均在境内完成

## 配置示例

```yaml
tenant:
  data_cross_border_enabled: false  # 默认不跨境
```

## 参考资料

- PIPL §38 — 向境外提供个人信息的条件
- PIPL §39 — 境外接收方的义务
- 处理 100 万人以上个人信息的须通过安全评估
