# eu-04: 数据留存期限声明 (Data retention period declaration)

> 法规: GDPR Art.13(2)(a) | 等级: high | 地区: EU

## 违规说明

未声明个人数据的存储期限。GDPR 要求数据控制者告知数据主体个人数据将被存储多长时间，或确定该期限的标准。

## 补救步骤

1. 确定对话数据的留存天数（建议根据业务需要设定，如 90 天、180 天）
2. 配置留存期限：设置 `tenant.data_retention_days`
3. 在隐私政策中注明数据留存期限

## 配置示例

```yaml
tenant:
  data_retention_days: 90
```

## 参考资料

- GDPR Art.13(2)(a) — Period for which the personal data will be stored
- GDPR Art.5(1)(e) — Storage limitation principle
