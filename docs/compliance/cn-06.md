# cn-06: 训练数据合规声明 (Training data compliance declaration)

> 法规: PIPL §24 + 网信办《生成式 AI 管理暂行办法》§7 | 等级: medium | 地区: CN

## 违规说明

未声明训练数据来源和处理的合规性。《暂行办法》要求使用合法来源的训练数据，不得侵犯知识产权，且须对训练数据进行标注质量评估。

## 补救步骤

1. 确认训练数据合规：将 `tenant.training_data_compliance` 设为 `true`
2. 整理训练数据来源清单，确保数据获取合法
3. 在服务条款中声明训练数据的合规处理方式

## 配置示例

```yaml
tenant:
  training_data_compliance: true
```

## 参考资料

- 网信办《生成式人工智能服务管理暂行办法》§7 — 训练数据合规要求
