# cn-04: 用户真实身份验证 (User identity verification)

> 法规: 网信办《互联网用户账号管理》§8 | 等级: high | 地区: CN

## 违规说明

未对用户进行真实身份验证。互联网信息服务提供者须按"后台实名、前台自愿"原则对用户进行基于真实身份信息的认证。

## 补救步骤

1. 启用身份验证：将 `tenant.user_identity_verification` 设为 `true`
2. 接入手机号或身份验证服务，确保后台可关联用户真实身份
3. 前台展示名称可由用户自主设定

## 配置示例

```yaml
tenant:
  user_identity_verification: true
```
